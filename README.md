## 📌 Project Overview

**ගජ වංශය LK** is a beautifully designed Sinhala interactive website created to showcase the living heritage of Sri Lankan elephants.  
This project combines **wildlife education, cultural storytelling, conservation awareness, interactive maps, animated UI, quiz learning, and profile-based exploration** into one clean static web experience.

The website is built as a **single-page interactive static website** using:

- ✅ HTML  
- ✅ CSS  
- ✅ JavaScript  
- ✅ Responsive UI  
- ✅ Animations  
- ✅ LocalStorage  
- ✅ Image fallback handling  
- ✅ Vercel deployment support

### ❤️ Favorite Elephant Save System

Users can save their favorite elephant profiles using the heart button.

Features:

- Save favorite profiles  
- Remove saved profiles  
- Favorites stored using `localStorage`  
- Saved list visible on the page  
- Data remains after page refresh

### 🔍 Search & Filter System

Users can search and filter elephant profiles by:

- Name

- Tags  
- Keywords

- Conservation stories

### 🛡️ Ethical Wildlife Tourism Checklist

Interactive responsible visitor checklist with progress tracking.

Users can tick responsible actions such as:

- Do not feed elephants  
- Keep a safe distance  
- Do not throw plastic  
- Follow guide instructions  
- Avoid flash and loud noise  

When completed, the user unlocks an:

🏆 **Elephant Guardian Badge**
